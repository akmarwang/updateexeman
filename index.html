UpdateExeMan

UpdateExeMan 是一個個人使用的檔案備份工具，以 PowerShell 腳本將本機的 Excel 工作簿定期上傳至使用者本人的 Google Drive，作為備份用途。

UpdateExeMan is a personal backup tool that uploads a local Excel workbook to the user's own Google Drive on a schedule.

功能說明

本工具僅使用 Google Drive API 的 drive.file 權限，只能存取由本工具自行建立的檔案與資料夾，無法讀取使用者雲端硬碟中的其他檔案。本工具不對外提供服務，僅供開發者本人使用。
